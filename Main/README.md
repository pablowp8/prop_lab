# PROP-Lab — Laboratorio Virtual de Propulsión Aeroespacial

Aplicación interactiva para el análisis termodinámico de aerorreactores:
monoeje (con y sin postcombustor), turbofán de flujos separados y turbohélice.

Permite variar parámetros de diseño (M_0, T_t4, OPR, BPR, FPR, α_pw, eficiencias…)
y visualizar en tiempo real empuje, rendimientos motor/propulsor/motopropulsor,
diagrama del motor y telemetría.

Desarrollado en la ETSIAE — Universidad Politécnica de Madrid.
